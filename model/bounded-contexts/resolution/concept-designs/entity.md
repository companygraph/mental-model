# Entity

> One page read as an entity of the graph, known by its id, its type and its canonical name.

## Attributes

| Attribute | Term | Type | Many | Description |
| --- | --- | --- | --- | --- |
| Id | | id | | The entity's id |
| Type | | string | | Its type, read from the folder its page sits in |
| Name | | string | | Its canonical name, the page's H1 |
