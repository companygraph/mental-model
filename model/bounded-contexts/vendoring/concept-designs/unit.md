# Unit

> A body of vocabulary vendored whole into its own folder under the units folder: core, which every instance takes, or a pack it chose. A unit comes from the same release as every other unit beside it.

## Attributes

| Attribute | Type | Description |
| --- | --- | --- |
| Name | string | `core`, or the name of the pack |
| Folder | string | `<units>/<name>/`, where its files sit |
