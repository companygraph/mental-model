# Name

> An entity a tool's answer listed without answering with it whole, given by its id and title so the page can link the title wherever the answer writes it. An entity the message cites is never also a name.

## Attributes

| Attribute | Type | Description |
| --- | --- | --- |
| Id | id | The entity's id, as the host gave it |
| Title | string | The title the page looks for in the answer's text |
