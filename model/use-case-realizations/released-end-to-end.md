# Released end to end

> Every step and every extension is in the latest releases, and a test in one of them walks the main success scenario.

## What it means

A use case is Released end to end when every step of its main success scenario and every extension is in the latest release of the product that carries it, and at least one test in such a release walks the scenario and observes what its success guarantees promise, which an `## Evidence` row that `verifies` names at the release's tag. A use case that runs across several products reads each step against the release of the product that takes it. A page enters the level when the last of the two ships, and moves down to Main scenario released when a release drops an extension or the test. While a use case is Released end to end, a reader may rely on every way it can go, as its page tells them.
