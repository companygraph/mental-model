# Will a new CompanyGraph release break our model?

> The decision says who decides when a new release of core reaches a company's model, and what was weighed against letting it arrive by itself, the pin says how the model names the release it is written against, and the requirements say that a model is checked only against the release it adopted and that a move is shown before it is written.
