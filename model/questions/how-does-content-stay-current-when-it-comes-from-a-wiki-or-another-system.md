# How does content stay current when it comes from a wiki or another system?

> Every page declares the source it comes from, as every page here declares Local, and its id there where the source issues one, which is all a sync needs. The sync itself is the company's to choose, and the one we prefer is an agent reading the source over MCP, such as Atlassian's MCP server for Confluence and Jira, writing the pages the checks then hold.
