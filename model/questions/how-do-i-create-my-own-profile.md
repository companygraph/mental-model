# How do I create my own profile?

> The feature says how an agent writes a profile from a person's own documents, the profile a CV is derived from, the requirement says the documents are used only under that person's consent, and the command that starts an instance says how to get the model it is written into.

## Rests on

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| feature | A profile is written from a person's documents | | how a profile is written |
| feature | An instance is made and kept from one command | | the model it is written into |
| requirement | A person's documents are used only under that person's consent | | that the documents need the person's consent |
