# Can an agent change our model through the MCP server?

> The requirement says the server has no write path and how the model moves instead, the decision on the server says what was weighed against one, and the decision on who writes says how an agent's change still reaches the model, through the repository and a person's approval.

## Rests on

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| requirement | No call changes the model | | no write path, and how the model moves |
| decision | The server only reads, and answers at one named commit | | what else was weighed |
| decision | Agents write the model, and a person approves every change to it | | how an agent's change gets in |
