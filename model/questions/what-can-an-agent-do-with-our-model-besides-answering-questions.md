# What can an agent do with our model besides answering questions?

> The first feature says which procedures an agent follows on an instance, from building it to validating and publishing it, the second says what it can ask the model, and the decision says which agent they are written for first.

## Rests on

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| feature | An agent does the work no script can, by the skills an instance ships | | the procedures |
| feature | An agent reads the model | | what it can ask |
| decision | Claude is the first agent an instance supports, and not the only one | | which agent first |
