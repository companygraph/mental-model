# Understand

> Turn what somebody asked for into the page they could not write.

## What it takes

A GitHub issue on the repository the request is about, from anyone, in whatever words they brought.

## Activities

1. The Owner reads the request as it was written, before restating it.
2. The Owner establishes what the asker was trying to describe and could not — the entity, the field or the rule that was missing when they stopped.
3. The Owner asks for that where it is absent, and asks for nothing else; a request is not a form to be completed.
4. The Owner restates the request as the gap it is, in the issue, and lets the asker correct the restatement.

## What it produces

| Deliverable | Description |
| --- | --- |
| Restated request | The request written as the page that could not be written, agreed with whoever raised it |

## What it never does

- Never rewrites the asker's words as the record; the restatement sits beside them.
- Never decides whether the gap is real.
- Never asks which company the request comes from.

## Gate

To leave Understand, all of these hold:

- The request names the entity, the field or the rule that was missing.
- Whoever raised it has seen the restatement and not disputed it.

Where they cannot be met, the Owner says so in the issue and closes it as not understood, which is an answer and is not a refusal.
