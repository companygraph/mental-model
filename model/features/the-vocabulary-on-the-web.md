# The vocabulary on the web

> Anyone can read the vocabulary, and see it describe a company, in a browser and without cloning a repository.

## Description

The model page is the model, drawn: every type of core and of each pack the vocabulary ships, with its schema, as the graph of what references what, from a pinned commit of the vocabulary. The page around the drawing reads in English and Swiss Standard German; the drawing itself stays in the vocabulary's one language, English. The example page is one company, drawn: a fictional company described in that vocabulary, from the same commit. Both are also published as files an agent can fetch. It stops at reading: nothing on the web writes to a model, and what the site must say and how it is built belong to the companygraph.io website.
