# An instance is made and kept from one command

> Someone starts a company's model, checks it, moves it to a newer vocabulary and puts the editor beside it, from one menu and without installing anything first.

## Description

One command, run from a release on GitHub, opens a menu that does all of it: it makes an instance in a folder, with the vocabulary vendored, a manifest naming every file it owns, a folder per type, the entities no instance passes without, a workflow and the agent files, so that the instance passes the checks on its first day; it runs the mechanical checks as the instance's own workflow runs them; it moves an instance to a newer release, its vendored core, its skills, its manifest and its workflow together; and it installs the Obsidian plugin in a vault or updates it there. Each pick reports what it did and the menu comes back. It stops at the instance's shape and its tooling: what a company writes into the folders is the company's, and writing a page from its schema is not among the picks.
