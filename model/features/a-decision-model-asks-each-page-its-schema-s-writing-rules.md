# A decision model asks each page its schema's writing rules

> A company learns which of its pages most likely break a writing rule before anyone reads them, and decides first exactly what leaves its hands to find out.

## Description

Each bullet of a schema's writing rules becomes a typed question, asked of every page of that type, and a decision model outside the machine answers each with a choice and how likely it is. Before anything is sent, the owner is shown the pages, the questions, the service, what the run will cost and a digest of it all, and only a yes to that digest sends exactly those files; a no sends nothing. The report flags the pages whose answers fall below a band measured against the one model it names, and the agent pass reads those first. It stops at advice: it changes no page, a flag counts only once it has been read against its page, and the agent pass still reads every page the report does not flag. Which model answers is the tooling's pinned choice, and another is measured before it is named.
