# An agent does the work no script can, by the skills an instance ships

> Someone asks an agent to build a company's model from its web address, write a person's profile from their documents, check every page against its schema's writing rules or publish the model somewhere, and the agent follows the procedure that ships with the instance instead of improvising one.

## Description

The procedures an agent follows where the work is a judgment and not a rule: building an instance from what a company publishes, writing or extending a profile from a person's documents, recording the terms a source is published under and the consent it needs, validating an instance with the agent pass beside the mechanical checks, producing the content of a surface, and exporting the instance for an agent or a notebook to read. `init` installs them, each where the agent the instance was made for reads it, and every upgrade moves them with core, so an instance follows the procedures of the release it names. Each skill proposes, writes against the schemas and runs the checks; the operator decides every level, seat and sentence, and the commit is theirs. It stops at the files: merging stays with a person, and a procedure a company writes for itself is its own and not part of this feature.
