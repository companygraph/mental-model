# A visitor asks the model

> Someone on a page asks a company's model a question in their own words and gets an answer that names the entity each claim rests on.

## Description

A chat over any instance's MCP server, opened from a button on a site's page: it asks the server's tools what the model says, writes the answer from what they returned, and names and links the entity each claim rests on, so a visitor can check it without connecting an agent of their own. It holds no model and pins no commit; it answers from whatever the server it is deployed beside serves. It stops at the question: what the model says is the server's, where it runs and what it may spend is each deployment's own, and where the model does not say, the answer says so rather than filling the gap.
