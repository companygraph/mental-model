# A profile is written from a person's documents

> Someone hands an agent a folder of a person's CVs, diplomas, certificates and reference letters and gets back a profile the model can hold: the periods, the skills they show and the levels those skills earned.

## Description

A procedure an agent follows, shipped as a skill with every instance and moved with it on every upgrade, because what a period shows and what level a claim has earned are judgments no script makes. It asks whether to create a profile or extend one, reads every document in the folder, reuses the skills, levels, kinds and roles the model already holds and proposes only what is missing, writes the experiences and the profile against their schemas, and runs the checks and the agent pass. The operator decides every level, every seat and every sentence said in the person's own voice, and the commit is theirs. A CV is derived from what it writes: the profile says what the person claims and the experiences it owns say what happened, when and where, each claim resting on its evidence, so the CV is drawn from them and never kept beside them. Deriving one is not part of this feature. It stops at the documents: a fact no schema has a place for is left out and written down nowhere, and publishing the profile is a separate step.
