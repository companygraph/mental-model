# Deployment

> Software CompanyGraph builds, releases and deploys to a platform it rents or takes free.

## What it means

A deployment is made of code in CompanyGraph's own repositories, built and deployed by those repositories' workflows on a merge, and run on a platform. It is not SaaS, which a vendor builds and runs and CompanyGraph only connects to, and not a platform, which is what a deployment runs on. Nor is it the `service` type: a service is what a deployment exposes to others, with a page of its own.
