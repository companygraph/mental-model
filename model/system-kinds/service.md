# Service

> Software CompanyGraph builds and runs itself, on a platform it takes from a provider.

## What it means

A service is software whose code sits in CompanyGraph's own repositories, released by its own seats and deployed by them to a platform, where they run it. It is not SaaS, which a vendor builds and runs and CompanyGraph only connects to, and not a platform, which is what a service runs on.
