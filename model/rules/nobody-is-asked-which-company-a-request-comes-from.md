# Nobody is asked which company a request comes from

> Nobody who asks for vocabulary or tooling is asked which company they ask for, and a name they offer is not repeated.

## Why

A request is worth what it says about the shape a company could not describe, and that shape is the same whoever holds it. The vocabulary names no company it was drawn from, so knowing which one asked would only put a name where we have said none goes.
