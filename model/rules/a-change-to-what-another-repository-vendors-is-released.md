# A change to what another repository vendors is released

> A change to what another repository vendors reaches it only in a release whose notes say what it asks of a consumer: a re-sync, a re-pin or more than either.

## Why

What we make is taken as a tag with its notes, and a repository that vendors it moves to a later release only when it decides to. A change with no release has made every copy of it stale without telling anyone, and notes that do not say what a consumer must do leave each one to find out by breaking.
