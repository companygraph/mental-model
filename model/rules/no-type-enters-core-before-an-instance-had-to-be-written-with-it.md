# No type enters core before an instance had to be written with it

> No type enters core before an instance has had to be written with it.

## Why

A schema reviewed by its author agrees with itself, so the only evidence that a type holds a company is a company being held by it. Since August 23, 2026 the vocabulary grows from companies actually being described in it, and a type asked for, specified or approved before any instance needed it would be a proposal shipped as vocabulary.
