# The model is corrected first

> Where something we publish — a page, a site, a release, an answer — disagrees with the model, the model is corrected first and the thing is rebuilt from it; nothing is released while the disagreement stands.

## Why

Every surface we publish is derived from the model at a commit it names, and nothing is kept beside the model, so when a page and the model disagree it is the page that is wrong. A page fixed by hand and left disagreeing with the model is a second source that the next build overwrites or, worse, contradicts; correcting the model first keeps one place where a fact is true.
