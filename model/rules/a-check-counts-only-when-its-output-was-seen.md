# A check counts only when its output was seen

> A check counts as passed only when its output, from a run over the change as it now stands, has been read; a report that it passed is not its output, and a check that finds nothing counts only once it has been shown to find something.

## Why

A report is a claim, and the person or agent writing it is the one least placed to see what it missed, whether it comes from a seat of ours or from a contributor. A check run over an earlier state says nothing about the change as it stands, and a search that returns nothing may never have been asking the right question. The person at a gate decides on what the checks showed, so only an output, read, of a check that can find something tells us the change holds.
