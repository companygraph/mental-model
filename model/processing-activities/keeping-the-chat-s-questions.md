# Keeping the chat's questions

> Keeping each question the chat was asked, and whether the model could answer it, so that the person who runs the site sees what the model cannot yet say.

## Data subjects

- Visitors who open the chat and send a message

## Personal data

- The question a visitor sent, kept without their address and without the answer

## Processors

| Processor | Receives |
| --- | --- |
| Google Cloud | The question and whether the model could answer it, kept in its Zürich region with the weekly report made from them |
