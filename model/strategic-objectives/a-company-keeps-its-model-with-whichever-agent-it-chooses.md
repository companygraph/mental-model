# A company keeps its model with whichever agent it chooses

> The agent a company works with is chosen when its instance is made and can be changed at any time after, and whichever it chooses — Anthropic's Claude, OpenAI's ChatGPT, Google's Gemini or another — reads, writes and checks the model under the same rulebooks, with nothing lost in the change.

## What it makes true

Every procedure an instance ships is installed where the chosen agent reads it, and changing agents later is one command that leaves the model, its history and its checks untouched. It fails the day a company has to rewrite a page or give up a procedure because it changed agents, or the day a procedure ships that only one agent can follow.

What falls outside: which agent is best at the work, which is the company's call and not ours, and the agents' own terms and prices. Also outside: the model itself, which is Markdown and belongs to no agent already; this objective is about everything that works on it. And the model behind the chat we run on our own sites, which is a call about our deployment and not about what a company adopts.
