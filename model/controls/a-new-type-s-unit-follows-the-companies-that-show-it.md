# A new type's unit follows the companies that show it

> A new type is specified for core only where its sources show it in companies of more than one kind, for a pack where they show one kind, and not at all where they show a single company.

## How it is carried out

The Specifier, in Spec, for every new type, through the skill that writes vocabulary specifications: the research behind the type counts the companies its sources show it in, and the unit is decided from that count, core only where companies of more than one kind have the type, a pack where one kind has it, and a wait for the second company where only one has it; the specification states the count and the sources it rests on, so the Owner reads the evidence before giving the word. Nothing refuses a specification without a count, so the control holds as long as a new type is specified through the skill.
