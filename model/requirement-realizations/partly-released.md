# Partly released

> The latest release meets part of the requirement, and the page says what is missing.

## What it means

A requirement is Partly released when the latest release of the product it applies to meets part of it, which at least one `## Evidence` row names at the release's tag, and its `## Realization` says which part no release meets yet. A page enters the level when a release ships the first part, moves up to Released when a release ships the last, and moves down to Not released when a release drops what it had. While a requirement is Partly released, a reader may rely on the part the page names as released and on nothing its `## Realization` names as missing.
