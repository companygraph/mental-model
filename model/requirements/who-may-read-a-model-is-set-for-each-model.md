# Who may read a model is set for each model

> Each model can be read by exactly the accounts its company sets, by anyone where the model is published.

## Why

A company publishes one model and keeps another private, and that is never the store's to decide.

## Fit criterion

A model set private cannot be read by an account outside it, and a published one is read without an account. Today a repository's visibility meets it.
