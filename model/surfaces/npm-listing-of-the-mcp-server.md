# npm listing of the MCP server

> The page a developer finds when they search npm for the MCP server: the package a release published from its tag, with how to install it and where it came from.

## What it shows

- **Readme** — the MCP server's README at the version shown.
- **Install** — the command that adds the package by its name.
- **Version** — the newest version, which the newest release published.
- **Provenance** — the repository, the commit and the workflow run a version was built from.
- **Repository** — the GitHub repository the package's `repository` field names.
- **License** — the license the package declares.
- **Versions** — every version published, each one a release's tag.

## Constraints

- Every version after the first carries a provenance statement naming a commit of companygraph/mcp-server and the run of `.github/workflows/publish.yml` that published it.
- The newest version is the newest release on GitHub, or a release whose publish run is waiting for the owner.
